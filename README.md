# Azure Enterprise AI Platform

A reusable, secure, and observable enterprise AI platform built on Microsoft Azure.

The platform combines data engineering, retrieval-augmented generation (RAG), agent workflows, traditional machine learning, evaluation, monitoring, and automated deployment.

## Business Scenarios

### Benefits Operations

- Answer benefit-policy questions with supporting citations.
- Retrieve synthetic claim information through an API.
- Escalate uncertain or sensitive requests to a human.

### Manufacturing Operations

- Answer questions using equipment manuals and safety procedures.
- Retrieve maintenance and inventory information.
- Create maintenance work orders after human approval.

## Planned Architecture

- Microsoft Foundry and Azure OpenAI
- Azure AI Search
- Azure Blob Storage and Azure Functions
- Azure Databricks and Delta Lake
- Azure Machine Learning and MLflow
- FastAPI and Azure Container Apps
- LangChain and LangGraph
- Microsoft Entra ID and managed identities
- Application Insights and OpenTelemetry
- Bicep, GitHub Actions, and Azure DevOps
